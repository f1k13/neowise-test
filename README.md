# Тестовое Neowise. AI-помощник для входящих заявок

Менеджер вводит текст заявки, получает тему и черновик ответа. Он читает результат и сам решает, что отправить клиенту.

## Запуск

В репозитории есть сервер, HTML-страница и имитатор модели. Нужен Node.js 20 или новее. Зависимостей и ключей нет.

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно задать через переменную `PORT`.

## Тесты

```sh
node --test server.test.mjs
```

Тесты сами запускают сервер на свободном локальном порту и проверяют HTTP-ответы для неверного ввода, успешного разбора и всех сценариев сбоя имитатора.

Для проверки страницы введите «Когда доставка?» и убедитесь, что появились тема и черновик. Затем отправьте `[timeout]`: вместо предыдущего черновика должна появиться подсказка о ручном разборе. Другие метки сбоя: `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]`.

## Поведение API

`POST /api/triage` принимает JSON с непустой строкой `text`. Пустой или нестроковый `text`, отсутствующее поле и битый JSON дают HTTP 400 с `{"status":"invalid_input"}`.

Сервер ждёт модель до 300 мс и проверяет её JSON: тема должна быть `delivery`, `pricing` или `other`, а `draft` — строкой с непробельным содержимым. Корректный ответ возвращается с HTTP 200 и статусом `ready`. При таймауте, ошибке или некорректном результате сервер возвращает HTTP 200 с `{"status":"manual_review","topic":null,"draft":null}`. Страница показывает инструкцию для ручного разбора вместо прежнего черновика и сохраняет текст заявки.
